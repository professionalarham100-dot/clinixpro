🗄️ DATABASE SCHEMA
═══════════════════════════════════════════════════════════════════════════════

TABLES (11 Total):

1. USERS
   • user_id (PK)
   • email (unique)
   • password (hashed)
   • user_type (doctor, patient, admin, staff)
   • status (active, inactive)
   • timestamps

2. PATIENTS
   • patient_id (PK)
   • name, email, phone
   • dob, gender, blood_group
   • medical_history, allergies
   • emergency contacts
   • timestamps

3. DOCTORS
   • doctor_id (PK)
   • name, email, phone
   • specialization, department
   • qualifications, license_number
   • consultation_fee
   • office_hours, availability
   • timestamps

4. APPOINTMENTS
   • appointment_id (PK)
   • patient_id (FK)
   • doctor_id (FK)
   • appointment_date, reason
   • status (scheduled, completed, cancelled)
   • notes, timestamps

5. MEDICAL_RECORDS
   • record_id (PK)
   • patient_id (FK)
   • doctor_id (FK)
   • diagnosis, symptoms
   • treatment_plan, follow_up_date
   • timestamps

6. PRESCRIPTIONS
   • prescription_id (PK)
   • appointment_id (FK)
   • patient_id (FK)
   • doctor_id (FK)
   • prescription_details (JSON)
   • status, dates, timestamps

7. BILLING
   • bill_id (PK)
   • patient_id (FK)
   • appointment_id (FK)
   • consultation_fee, medicines_cost
   • total_amount, paid_amount
   • payment_status, payment_method
   • invoice_number, timestamps

8. TASKS
   • task_id (PK)
   • assigned_to (FK)
   • related_patient_id (FK)
   • title, description
   • status, priority, due_date
   • timestamps

9. STAFF
   • staff_id (PK)
   • name, email, phone
   • role, department, status
   • timestamps

10. ACTIVITY_LOGS
    • log_id (PK)
    • user_id, user_type
    • action, entity_type, entity_id
    • changes (JSON), ip_address
    • created_at

11. VIEWS (3)
    • today_appointments
    • patient_records_summary
    • doctor_statistics

🚀 GETTING STARTED
═══════════════════════════════════════════════════════════════════════════════

QUICK START (5 Minutes):

1. Database Setup:
   mysql -u root -p
   CREATE DATABASE smart_clinic;
   USE smart_clinic;
   SOURCE database/schema.sql;
   SOURCE database/sample_data.sql;

2. Backend Setup:
   cd backend
   python -m venv venv
   venv\Scripts\activate (Windows) or source venv/bin/activate (Mac/Linux)
   pip install -r requirements.txt
   cp .env.example .env
   python app.py

3. Frontend:
   Open frontend/index.html or
   cd frontend
   python -m http.server 8000

4. Access:
   Frontend: http://localhost:8000
   Backend API: http://localhost:5000/api
