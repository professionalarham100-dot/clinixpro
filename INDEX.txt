🚀 QUICK START IN 3 STEPS
════════════════════════════════════════════════════════════════════════════

STEP 1: Database Setup
─────────────────────────────────────────────────────────────────────────
  1. Open MySQL:
     mysql -u root -p
  
  2. Run:
     CREATE DATABASE smart_clinic;
     USE smart_clinic;
     SOURCE database/schema.sql;
     SOURCE database/sample_data.sql;
  
  3. Exit MySQL

STEP 2: Backend Setup
─────────────────────────────────────────────────────────────────────────
  1. Open Terminal/CMD in project folder
  
  2. Navigate to backend:
     cd backend
  
  3. Create environment:
     python -m venv venv
  
  4. Activate (Windows):
     venv\Scripts\activate
     OR activate (Mac/Linux):
     source venv/bin/activate
  
  5. Install dependencies:
     pip install -r requirements.txt
  
  6. Setup environment file:
     copy .env.example .env
     (Edit .env with your database credentials)
  
  7. Start server:
     python app.py
  
  ✅ Server running on http://localhost:5000

STEP 3: Frontend Setup
─────────────────────────────────────────────────────────────────────────
  1. Open another Terminal/CMD in project folder
  
  2. Navigate to frontend:
     cd frontend
  
  3. Start server:
     python -m http.server 8000
  
  ✅ Frontend on http://localhost:8000

⚠️ TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

DATABASE CONNECTION FAILED:
  → Check MySQL is running
  → Verify credentials in .env
  → Check database name

PORT ALREADY IN USE:
  → Kill process on port 5000 or 8000
  → Use different port in .env

MODULE NOT FOUND:
  → Activate virtual environment
  → Reinstall: pip install -r requirements.txt

CORS ERRORS:
  → Ensure backend on http://localhost:5000
  → Ensure frontend on http://localhost:8000

See SETUP.md for more troubleshooting tips.
